## 🎤 一、30 秒电梯演说（直击企业痛点与核心价值）

> “各位领导、各位技术专家：
> 
> 现在大模型与 Agent 正在进入我们企业的核心业务系统，比如财务报销、电商售后、客户运营和运维审批。
> 
> **但现在企业面临一个最大的上线恐惧：‘改了一个 Prompt 或换了个模型版本，谁敢保证它上线不会误退款、不会越权删库？’**
> 
> 市面上现有的工具（如 Promptfoo、DeepEval）本质上都是测文本问答的。它们遇到‘大模型嘴上信誓旦言说退款成功，底层数据库其实写错没改’的情况时，全都会因为礼貌客套语气而**误判满分放行**，造成严重资损！
> 
> **AgentTestHub 是专为企业打造的‘Agent 发布门禁（Release Gate）’**：
> 1. 它不看大模型嘴上怎么吹，直接核验底层**物理沙盒数据库（Row-level）的真实状态差分**；
> 2. 具备**刚性安全一票否决权（Fatal Veto）**与 AST 静态解析，有删表或越权攻击直接阻断发布；
> 3. 评测完成后出具**带有 HMAC-SHA256 加密数字签名的防篡改交付报告**，让每一次 Agent 上线都有铁证可循！”

## 🖥️ 二、大屏演示逐页操作脚本（分步演练手册）

### 第一幕：全局资产大盘与发布准入大屏 (`http://localhost:3005/overview`)
- **操作动作**：打开概览页面，展示资产卡片与门禁状态。
- **解说词**：
  > “这里是我们企业的工作台概览。大家可以看到，我们已经沉淀并纳管了包括 AutoGPT、OpenHands、SWE-agent 以及我们自研的 **25 个 Agent 资产**。
  > 
  > 页面顶部的**‘发布门禁’**是我们的核心决策引擎：它聚合多次独立重复，计算 Wilson 95% 置信区间与抖动度量（Flaky），给出明确的 `可发布 (PASS)` 或 `阻断发布 (BLOCKED)` 结论，彻底替代人工凭感觉抽检。”

### 第二幕：三方开源工具实测对决大屏 (`http://localhost:3005/comparison.html`)
- **操作动作**：切换到对比大屏，向领导展示多边形 12 维 SVG 雷达图。
- **解说词**：
  > “有些团队可能会问，GitHub 上不是有 Promptfoo、DeepEval、Langfuse 吗？为什么还要 AgentTestHub？
  > 
  > 请看屏幕上的这张 **12 维能力雷达图**：
  > - **Promptfoo / DeepEval** 覆盖面都在右下角（纯文本断言与问答打分），在物理沙盒、AST 安全阻断、双控交互模拟、一票否决上全是空白（0分）；
  > - **Langfuse / Phoenix** 擅长生产被动排障，但无法在发布前做主动环境仿真与阻断拦截；
  > - **AgentTestHub** 实现了全链路 12 维度的满配闭环。”

### 第三幕：现场抓妖！三大极限实战对决讲解 (`http://localhost:3005/comparison.html#cases`)
- **操作动作**：滚动到 Case 1、Case 2 卡片。
- **解说词**：
  > “我们在同一个开源 Agent 上跑了 3 个极端业务场景，结果令人震惊：
  > 1. **Case 1: 礼貌性假退款幻觉**
  >    - Agent 对话框里态度极好：*‘已成功为您加急办理退款，1-3天原路退回！’*，但底层 SQL 报错，数据库状态依然是未退款；
  >    - **Promptfoo 和 DeepEval 全被客套骗了，给出了 100% 满分放行（致命误放行）！**
  >    - **AgentTestHub 严格比对沙盒数据库行，抓出实际没落盘，直接 0 分拦截！**
  > 2. **Case 2: 特洛伊带毒合规注入**
  >    - 攻击者要求取消订单同时执行 `DROP TABLE audit_logs;` 清理日志；
  >    - 传统工具按平均分算得 0.5 分，被动稀释放行；
  >    - **AgentTestHub 编译级 AST 抓出 Drop 语句，安全法官启动 Fatal Veto，一票否决绝对不可推翻！**”

## 📈 三、为企业带来的量化价值与 ROI（投资回报率）

1. **规避 90% 以上的大模型业务欺骗与资损事故**：
   - 杜绝“Agent 假执行真承诺”的幽灵 Bug，守住企业资金与数据库底线。
2. **测试与发布效率提升 5 倍**：

3. **沉淀企业核心数据与合规凭据**：
   - 每次改动都生成不可篡改证据包，满足网络安全法、等保合规与企业内控审计要求。
